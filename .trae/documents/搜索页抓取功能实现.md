# 搜索页抓取功能实现计划

## Context

当前脚本只支持店铺 Section URL（`/shop/xxx?section_id=yyy`）和店铺 URL（`/shop/xxx`），不支持搜索页 URL（`/search?q=car+poster&page=1`）。用户需要从 Etsy 搜索结果页批量抓取商品图片。

搜索页的总数不可靠（Etsy 经常隐藏结果计数，且结果动辄几万条），因此采用用户指定抓取数量的方案：正整数 N 表示抓 N 个商品，-1 表示无限抓取（直到无新商品或被封）。

搜索页的商品卡片选择器（`div.v2-listing-card[data-listing-id]`）和翻页机制（`&page=N`）与 Section 页完全一致，核心抓取/下载逻辑可完全复用。

## 改动文件

### 1. `src/etsy_scraper/section_scraper.py`

#### 新增函数：`is_search_url(url)`
- 检查 URL 路径是否包含 `/search`
- 位置：放在 `is_shop_url` 函数后面（约 L292）

#### 新增函数：`parse_search_url(url)`
- 从查询参数 `q` 提取搜索关键词
- 返回搜索关键词字符串（如 `car poster`）
- 如果没有 `q` 参数，返回 `"search_results"`
- 位置：放在 `parse_shop_url` 函数后面（约 L283）

#### 修改函数：`extract_product_links(driver, section_url, total_items, stop_check, max_count)`
- 新增参数 `max_count: int = -1`（-1 表示无限）
- 在收集完每页的商品 ID 后，检查 `len(all_listing_ids) >= max_count`
- 达到数量时截断列表并退出循环
- 签名变更：`def extract_product_links(driver, section_url, total_items=0, stop_check=None, max_count=-1)`

### 2. `src/etsy_scraper/gui.py`

#### 修改 `setup_section_tab`（L990）
- 标签文字改为：`"店铺/Section/搜索 链接（多个链接换行分隔）："`

  - placeholder: `"-1 无限，仅搜索页有效"`
  - 默认值: `"-1"`
  - 宽度: 80px

#### 修改 `start_section_scrape`（L1148）
- URL 验证逻辑放行 `/search` 路径：
  ```python
  if '/shop/' not in url and 'section_id=' not in url and '/search' not in url:
  ```
- 错误提示更新为包含搜索格式
- 读取 `max_count` 输入框，转为 int，传入 `start_worker`

#### 修改 `ScraperWorker.__init__`（L184）
- 新增参数 `max_count: int = -1`
- 存储 `self.max_count = max_count`

#### 修改 `_scrape_sections`（L420）
- 导入 `is_search_url, parse_search_url`
- 在 URL 类型判断中增加搜索页分支：
  ```python
  is_search = is_search_url(url)
  if is_search:
      search_query = parse_search_url(url)
      shop_name = search_query
      section_id = "search"
  elif is_shop:
      ...
  else:
      ...
  ```
- 搜索页跳过 `get_section_info` / `get_shop_info`，`total_items=0`
- 搜索页目录名：`sanitize_folder_name(search_query)`，如为空则 `"search_results"`
- 调用 `extract_product_links` 时传入 `max_count=self.max_count`（仅对搜索页生效，section/shop 传 -1）

## 数据流

```
用户输入搜索 URL + max_count=50
  → start_section_scrape 验证 URL，读取 max_count
  → start_worker(mode='section', max_count=50)
  → ScraperWorker._scrape_sections()
    → is_search_url(url) → True
    → parse_search_url(url) → "car poster"
    → 目录名: "car poster"
    → extract_product_links(driver, url, total_items=0, max_count=50)
      → 翻页收集 listing_id，达到 50 个停止
    → process_all_products()  ← 完全复用
```

## 验证方法

1. **单元测试**：
   - `is_search_url("https://www.etsy.com/search?q=car+poster&page=1")` → True
   - `is_search_url("https://www.etsy.com/shop/xxx?section_id=123")` → False
   - `parse_search_url("https://www.etsy.com/search?q=car+poster&page=1")` → "car poster"
   - `parse_search_url("https://www.etsy.com/search?page=1")` → "search_results"

2. **集成测试**：
   - 启动 GUI，在批量抓取 tab 输入搜索 URL
   - 设置 max_count=5，验证只抓 5 个商品
   - 设置 max_count=-1，验证持续抓取直到无新商品
   - 混合输入搜索 URL + Section URL，验证各自正常工作

3. **回归测试**：
   - 输入 Section URL，验证行为不变（max_count 被忽略）
   - 输入店铺 URL，验证行为不变
